# D.I.S.M.I.S. Field Workshop v2

Offline-first progressive web app with beginner-oriented survival workshop guides.

## Installation / GitHub Pages
Upload the files **inside this folder** (not the folder itself, and not `build.py`) to the root of your existing GitHub Pages repository. Replace files with matching names. GitHub Pages must deploy from main / root. Open the site online and refresh; then test in airplane mode.

## Limitations
This is an initial 18-guide workshop library, not the complete survival encyclopedia or an offline AI model. Some guides are feasibility/planning instructions rather than complete build schematics because exact electrical ratings, site conditions, and materials are essential for safe construction. Field notes and step progress use localStorage and can be cleared by the browser. Export notes regularly.

## Safety
Water treatment, electrical work, trapping, food preservation, and plant identification have serious hazards. Check authoritative local guidance and actual component manuals. No photo identification or external network features are provided.
